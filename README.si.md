# ගැලීම් සටහන් අනුකාරකය

ගැලීම් සටහනක් අඳින්න, **ධාවනය** ඔබන්න, එය එක් බ්ලොක් එකක් බැගින් ක්‍රියාත්මක වන ආකාරය නරඹන්න.

මෙය සාදා ඇත්තේ පෙර ක්‍රමලේඛන දැනුමක් නොමැති, 8-9 ශ්‍රේණිවල තොරතුරු හා සන්නිවේදන තාක්ෂණය (ICT) හදාරන සිසුන් (වයස 13-15) සඳහාය. සිසුන් බ්ලොක් කැන්වසය වෙත ඇදගෙන එයි, ඒවා ඊතල මගින් සම්බන්ධ කරයි, සරල ප්‍රකාශන ටයිප් කරයි, පසුව වත්මන් බ්ලොක් එක උද්දීපනය වෙමින්, ගමන් කළ ඊතලය සජීවනය වෙමින් ක්‍රියාත්මක වීම පියවරෙන් පියවර නරඹයි.

**ආදානය හා ප්‍රතිදානය සිදුවන්නේ බ්ලොක් මතමය.** අගයක් අසන බ්ලොක් එකම එය ටයිප් කරන ක්ෂේත්‍රය පෙන්වයි; මුද්‍රණය කරන බ්ලොක් එකම එය මුද්‍රණය කළ දේ පෙන්වයි. කොන්සෝලයක් ආදානය හා ප්‍රතිදානය එකම ධාරාවකට එකතු කරන්නේ ඒවා තැබීමට වෙනත් තැනක් නොමැති නිසාය — මෙහි එවැනි තැනක් ඇති නිසා, සිසුවාට ගැලීම් සටහනෙන් ඈත් බැලීමට අවශ්‍ය නොවේ. සම්පූර්ණ වාර්තාව අවශ්‍ය විටෙක බැලීමට වෙනම පැනලයක් ඇත.

මෙහි ඉගැන්වීමේ මූලික අදහස නම් **ගැලීම් සටහනක් යනු වැඩසටහනක්ම බවයි**. දෝෂ පණිවිඩ මෙහි ප්‍රධාන අංගයකි — සෑම දෝෂයක්ම වාක්‍යයක් සහ "දැන් කුමක් කළ යුතුද" යන ඉඟියක් බවට පරිවර්තනය වේ.

## බ්ලොක්

| බ්ලොක් | හැඩය | කරන දේ |
|---|---|---|
| ආරම්භය (Start) | ඕවලාකාර | වැඩසටහන ආරම්භ වන තැන. එකක් පමණක් තිබිය හැක. |
| නැවතුම (Stop) | ඕවලාකාර | වැඩසටහන අවසන් කරයි. කිහිපයක් තිබිය හැක. |
| ආදානය (Input) | සමාන්තරාස්‍රය | නතර වී, ටයිප් කරන අගයන් විචල්‍යයන් වෙත කියවයි. |
| ප්‍රතිදානය (Output) | සමාන්තරාස්‍රය | අගයන් ගණනය කර මුද්‍රණය කරයි. |
| ක්‍රියාවලිය (Process) | සෘජුකෝණාස්‍රය | පැවරුම්, පේළියකට එකක් බැගින්. |
| තීරණය (Decision) | දියමන්ති හැඩය | සත්‍ය/අසත්‍ය කොන්දේසියක්, `true` සහ `false` මාර්ග දෙකක් සමඟ. |
| සම්බන්ධකය (Connector) | කුඩා වෘත්තය | මාර්ග කිහිපයක් එකකට එකතු කරයි. |

**චක්‍රයක් සඳහා වෙනම බ්ලොක් එකක් නැත.** චක්‍රයක් යනු තීරණය බ්ලොක් එකක මාර්ගයකින් පෙර බ්ලොක් එකක් වෙත ආපසු යන ඊතලයකි — එයද ඉගැන්විය යුතු දෙයකි. සෑම බ්ලොක් එකකටම පැති හතරේම පෝට් ඇති නිසා, ආපසු යන ඊතලයට චක්‍රයේ යටින් වටේ නොගොස් පැත්තකින් පිටව යා හැක.

## ප්‍රකාශන භාෂාව

හිතාමතාම ඉතා කුඩාය. ක්‍රියාත්මක වීමේ පිළිවෙළ ගැලීම් සටහන මගින්ම දැක්වෙන නිසා, `if` හෝ `while` වැනි මූල පද ඉගෙනීමට අවශ්‍ය නැත.

```
expression := or
or         := and ( "OR" and )*
and        := not ( "AND" not )*
not        := "NOT" not | comparison
comparison := sum ( ( "=" | "<>" | "<" | ">" | "<=" | ">=" ) sum )?
sum        := term ( ( "+" | "-" ) term )*
term       := unary ( ( "*" | "/" | "%" ) unary )*
unary      := "-" unary | primary
primary    := NUMBER | STRING | "true" | "false" | IDENT | "(" expression ")"
```

- අගයන් යනු **සංඛ්‍යා, පෙළ, සහ `true`/`false`** පමණි. වෙනත් කිසිවක් නැත.
- **අගය සත්‍ය/අසත්‍ය ලෙස ස්වයංක්‍රීයව නොගැනේ.** `if 5` යනු දෝෂයකි, "5 යනු සත්‍යයි" යන්න නොවේ.
- `=` යනු ක්‍රියාවලිය බ්ලොක් එකේදී *පැවරුමයි*, තීරණය බ්ලොක් එකේදී *සමානතාවයයි*. එය පිහිටි තැන අනුව වෙනස හඳුනාගනී. මෙය මෙම මට්ටමේදී ව්‍යාජ කේත (pseudocode) උගන්වන ආකාරය වන අතර, `==` පැහැදිලි කිරීමේ අවශ්‍යතාව මග හරියි.
- දෙපැත්තෙන් එකක් පෙළ නම් `+` මගින් ඒවා එකට එකතු කරයි; අනෙකුත් ගණිත මෙහෙයුම් සංඛ්‍යා සඳහා පමණි.

**වැදගත්:** ටයිප් කරන කේතය සැමවිටම ඉංග්‍රීසියෙන් පවතී — `AND`, `OR`, `NOT`, `true`, `false` සහ විචල්‍ය නම්. සිංහලට පරිවර්තනය වන්නේ අතුරු මුහුණත පමණි.

### බ්ලොක් තුළ පේළි කිහිපයක්

බ්ලොක් එකක් තුළ Enter ඔබන විට එය ස්වයංක්‍රීයව විශාල වේ. පේළි කීයක් තිබුණත් බ්ලොක් එකක් සැමවිටම **එක් පියවරකි**.

```
ක්‍රියාවලිය               ආදානය            ප්‍රතිදානය
─────────────────       ────────────      ──────────────────────
subtotal = qty * price  price             "Receipt"
tax = subtotal / 10     qty               "qty:   ", qty
total = subtotal + tax                    "total: ", total
```

ක්‍රියාවලිය බ්ලොක් එකේ පේළි ඉහළ සිට පහළට ක්‍රියාත්මක වන අතර, එක් එක් පේළියට ඉහත පේළි ගබඩා කළ දේ පෙනේ. ආදානය බ්ලොක් එකේදී කොමාවක් හෝ නව පේළියක් නම් වෙන් කරන අතර, එක් එක් නම සඳහා වෙන වෙනම අගය අසයි. ප්‍රතිදානය බ්ලොක් එකේදී නව පේළියක් නව මුද්‍රණ පේළියක් ආරම්භ කරන අතර, කොමාවක් එකම පේළියේ අගයන් එකට එකතු කරයි.

## ක්‍රියාත්මක වීම නැරඹීම

**ධාවනය** ඔබන විට වැඩසටහන ක්‍රියාත්මක වේ; නැවත ඔබන විට **විරාමය** ලෙස තාවකාලිකව නවතී. **පියවර** මගින් අතින් එක් බ්ලොක් එකක් ඉදිරියට යන අතර, **පසුපසට** මගින් එය හරවා ගත හැක — `step()` පිරිසිදු ශ්‍රිතයක් වන නිසා පෙර තත්ත්වයන් ලැයිස්තුවක තබා ගැනීමෙන් මෙය කළ හැකි වේ.

වැඩසටහන ක්‍රියාත්මක වන අතරතුර:

- වත්මන් බ්ලොක් එක වටා වළල්ලක් ඇඳෙන අතර ගමන් කළ ඊතලය සජීවනය වේ. වළල්ල බ්ලොක් එකට *යටින්* ඇඳෙන නිසා, ක්‍රියාත්මක වන විටත් බ්ලොක් එකට තමන්ගේම වර්ණය රැඳේ.
- සෑම බ්ලොක් වර්ගයකටම වර්ණයක් ඇති අතර එය බ්ලොක් ලැයිස්තුවේත් කැන්වසයේත් එකමය — දම් පාට අසයි, නිල්කොළ පාට මුද්‍රණය කරයි, නිල් පාට අගය පවරයි, කහ පාට තීරණය කරයි.
- **ආදානය** බ්ලොක් එකට ක්ෂේත්‍රයක් සම්බන්ධ වී පෙනේ — විචල්‍ය නාමය, අපේක්ෂිත වර්ගය, සහ නම් කිහිපයක් ඇත්නම් `n/total` ද සමඟ. සංඛ්‍යාවක් අපේක්ෂිත තැනක පෙළක් ටයිප් කළහොත් දෝෂය එම ක්ෂේත්‍රයේම පෙන්වයි.
- **ප්‍රතිදානය** බ්ලොක් එක අවසන් වරට මුද්‍රණය කළ දේ පෙන්වන අතර, චක්‍රයක සෑම වටයකදීම එය යාවත්කාලීන වේ.
- විචල්‍යවල අගයන් කැන්වසය මත තීරුවක පෙනේ. වේගය සෙමින් සිට ක්ෂණික දක්වා තෝරාගත හැකි අතර, කැමරාව වත්මන් බ්ලොක් එක අනුගමනය කරයි — එය අවශ්‍ය නම් නැවැත්විය හැක.

වලංගුකරණය බ්ලොක් එක මතම ලකුණක් ලෙසත්, සම්පූර්ණයෙන් **පරීක්ෂණ** ටැබ් එකේත් පෙනේ. දකුණු පස ඇති වාර්තා පැනලය — **ප්‍රතිදානය**, **අගයන්**, **පරීක්ෂණ** — සාමාන්‍යයෙන් හකුළා ඇති අතර අවශ්‍ය විටෙක විවෘත කළ හැක.

**එළිය** සහ **අඳුරු** තේමා දෙකම ඇත; පෙරනිමිය එළිය තේමාවයි. මෙවලම් තීරුවේ මාරු කිරීමේ බොත්තමක් ඇත.

## ධාවනය කරන ආකාරය

```bash
pnpm install
pnpm dev
```

පසුව http://localhost:3000 විවෘත කරන්න. සියල්ල බ්‍රවුසරය තුළම ක්‍රියාත්මක වේ — සර්වරයක්, දත්ත ගබඩාවක් හෝ ගිණුමක් අවශ්‍ය නැත. කරන වැඩ `localStorage` හි ස්වයංක්‍රීයව සුරැකෙන අතර, JSON ලෙස අපනයනය හා ආනයනය කළ හැක.

## ව්‍යාපෘතියේ ව්‍යුහය

```
lib/          භාෂාව සහ අර්ථ නිරූපකය — පිරිසිදු TypeScript, React නැත
  lang/       ටෝකනකරණය, විග්‍රහය, AST, ගණනය කිරීම
  graph/      ලේඛන වර්ග, පෝට්, සම්පාදනය සහ වලංගුකරණය
  run/        ධාවන තත්ත්වය, step(), ආදාන හැසිරවීම, පියවර සීමාව
  errors/     දෝෂ කේත සහ ආසන්නතම නම් යෝජනා
  i18n/       කේතය + පරාමිති -> වාක්‍යය
components/   කැන්වසය, බ්ලොක්, පැනල, shadcn අතුරු මුහුණත
stores/       ගැලීම් සටහන (ලේඛනය) සහ ධාවනය (ක්‍රියාත්මක වීම)
messages/     en.json සහ si.json — පරිශීලකයාට පෙනෙන සෑම වාක්‍යයක්ම
docs/         නිර්මාණ සැලසුම් සහ ඒවා පිටුපස ඇති හේතු
```

ආදානය බ්ලොක් එකකට පුද්ගලයෙකු එනතුරු නතර වී සිටීමට සිදුවන නිසා, ක්‍රියාත්මක වීම චක්‍රයක් නොව තත්ත්ව යන්ත්‍රයකි (state machine):

```
ගැලීම් සටහන  ──compile()──▶  Program  ──step(program, state)──▶  ධාවන තත්ත්වය
```

`compile()` මගින් සෑම බ්ලොක් එකක්ම එක් වරක් විග්‍රහ කර ඊතල ඊළඟ බ්ලොක් වෙත යොමු බවට පත් කරයි. එබැවින් `step()` විග්‍රහ කිරීමක් හෝ ඊතල සෙවීමක් නොකරයි. `step()` යනු පිරිසිදු ශ්‍රිතයක් (pure function) වන නිසා, "ධාවනය" යනු එය නැවත නැවත ඇමතීම පමණි — තවද පෙර තත්ත්වයන් ලැයිස්තුවක තබා ගැනීමෙන් **පසුපසට** පියවර යාමද ලැබේ.

`lib/` කිසිවිටෙක React හෝ DOM භාවිත නොකරයි, එබැවින් සම්පූර්ණ භාෂාවම බ්‍රවුසරයක් නොමැතිව පරීක්ෂා කළ හැක. එම සීමාව ESLint මගින් බලාත්මක කෙරේ.

`lib/` තුළ දෝෂ කිසිවිටෙක වාක්‍ය ලෙස නොපවතී. අර්ථ නිරූපකය සාදන්නේ `{ code, params, span }` වන අතර, වෙනම පරිවර්තකයෙක් එය වාක්‍යයක් බවට පත් කරයි. එමනිසා දැනටමත් තිරයේ පෙනෙන දෝෂයක් වුවද, භාෂාව මාරු කළ විට අලුත් භාෂාවෙන් නැවත පෙන්වයි. එක් භාෂාවක ඇති යතුරක් අනෙකෙහි නොමැති නම් පරීක්ෂණයක් මගින් ගොඩනැගීම නවත්වයි.
